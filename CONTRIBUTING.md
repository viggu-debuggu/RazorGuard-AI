# Contributing to RazorGuard AI

Thank you for your interest in contributing! To get started: fork the repository, create a feature branch (`git checkout -b feat/your-feature`), make your changes with tests where applicable, ensure `cd backend && pytest` passes cleanly, and open a pull request against `main` with a clear description of what you changed and why. Please keep PRs focused — one logical change per PR — and follow the existing code style (structlog for logging, Pydantic schemas for all API I/O, and no new heavy dependencies without prior discussion in an issue).
